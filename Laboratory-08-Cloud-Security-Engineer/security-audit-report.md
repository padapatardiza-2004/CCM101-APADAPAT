# Security Audit Report

## Principle of Least Privilege (PoLP)

The Principle of Least Privilege ensures that users and services receive only the access permissions necessary for their intended functions. Applying this principle helps minimize unnecessary privileges and reduces the potential impact of unauthorized access.

## Attack Surface

An attack surface consists of the different points through which a system may be accessed or targeted. In a virtual machine, these points can include open network ports, active services, and user accounts. Reviewing these areas helps identify where additional security controls may be needed.

## Default Deny Policy

A Default Deny policy rejects incoming connections unless an existing firewall rule explicitly permits them. This approach limits access to approved services and reduces exposure to unexpected or unauthorized network traffic.
