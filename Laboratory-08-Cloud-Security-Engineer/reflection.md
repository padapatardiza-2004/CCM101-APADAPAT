# Mission Reflection

Through this laboratory activity, I gained a better understanding of how a host-based firewall helps protect a server. It controls incoming and outgoing network traffic and adds another layer of security by limiting connections that are not permitted.

I also learned that managing open ports is an important part of server security. Unnecessary open ports can increase the risk of unauthorized access. In this activity, I practiced allowing SSH for remote administration, permitting TCP port 8080 for the web application, and setting a Default Deny policy for incoming traffic.

In an enterprise environment, exposing a database port such as MySQL's port 3306 to the public internet can create security risks. Unauthorized users may attempt to access the database or exploit weaknesses in its configuration. For this reason, database connections should be limited to trusted systems and authorized users.
