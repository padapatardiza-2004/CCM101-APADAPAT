# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory activity focused on learning about cloud storage and object storage. We first compared Block Storage, File Storage, and Object Storage to understand their different uses. We then deployed MinIO using Docker in the KillerCoda Ubuntu Playground. After successfully deploying MinIO, we accessed its Web Console, created a bucket named `client-photos`, and uploaded a sample file.

## Objectives

The objectives of this laboratory activity are to:

- Understand the differences between Block Storage, File Storage, and Object Storage.
- Learn how object storage can be used for large amounts of data.
- Deploy MinIO using Docker.
- Configure MinIO using environment variables.
- Access the MinIO Web Console using port 9001.
- Create and manage an object storage bucket.
- Upload a sample file to the bucket.
- Practice using Linux and Docker commands.
- Document the deployment process using Markdown and GitHub.

## Tools Used

- KillerCoda Ubuntu Playground
- Ubuntu Linux
- Docker
- MinIO
- GitHub
- Web Browser
- Markdown

## Skills Learned

Through this laboratory activity, I learned how to compare different types of cloud storage and identify their appropriate uses. I also learned how to deploy MinIO using Docker and configure the container using environment variables.

I practiced Linux and Docker commands such as `docker pull`, `docker run`, and `docker ps`. I also learned how to map ports and access a web-based cloud service through port 9001.

In addition, I learned how to create a bucket and upload an object using the MinIO Web Console. This activity also improved my skills in documenting technical procedures and organizing laboratory files using GitHub.
