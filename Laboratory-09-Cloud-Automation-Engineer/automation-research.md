# Automation Research

## Bash Scripting

Bash scripting allows Linux users to place multiple commands in one file and execute them together. The `#!/bin/bash` line, known as the shebang, specifies that Bash will be used to run the script.

## Variables

Variables hold values that can be used throughout a script. For example, `$BACKUP_DIR` stores the location of the backup folder. Using variables makes the script easier to read and update because the same value does not need to be written repeatedly.

## Cron Jobs

Cron is a Linux utility that schedules commands or scripts to run at specific times. It is helpful for cloud automation because it can handle repeated tasks, such as creating backups, without requiring the user to start each task manually.
