# Cloud Infrastructure Components

## Compute Resources

### Purpose

Compute resources refer to the processing capabilities of a cloud server, such as its CPU and memory, which are used to execute programs, commands, and services.

### Why It Is Important

They are important because the server needs processing power and memory to handle workloads and perform different operations efficiently.

### Relation to the Linux Environment Provided by KillerCoda

In the KillerCoda environment, I examined the CPU model, number of CPU cores, and available RAM. The information showed me the computing capacity available for running Linux commands and performing server tasks.

## Storage Resources

### Purpose

Storage resources provide space for keeping operating system files, applications, user data, and other information required by the server.

### Why It Is Important

Storage is necessary because a cloud system needs enough space to save data and make files available whenever they are needed.

### Relation to the Linux Environment Provided by KillerCoda

I used `df -h` to check the disk capacity and usage, while `findmnt` allowed me to view the mounted file systems. These commands helped me see how storage is arranged within the KillerCoda Linux server.

## Networking Resources

### Purpose

Networking resources provide the connection that allows a server to exchange information with users, other computers, and cloud services.

### Why It Is Important

A reliable network is needed so that cloud resources can communicate with one another and provide access to applications and services.

### Relation to the Linux Environment Provided by KillerCoda

I used the `hostname -I` command in KillerCoda to identify the IP addresses assigned to the Linux environment. This gave me a better understanding of how the server is identified and connected within its network.

## Operating System

### Purpose

The operating system controls the server's hardware resources and provides the platform where commands, applications, and other services can operate.

### Why It Is Important

It is important because it coordinates the available hardware and software resources and provides users with a way to interact with the server.

### Relation to the Linux Environment Provided by KillerCoda

KillerCoda provided a Linux-based environment running Ubuntu 24.04.4 LTS. I used the terminal and Linux commands to examine different parts of the server, including its compute, storage, networking, and system information.
