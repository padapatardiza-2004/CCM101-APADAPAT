# Cloud Provider Comparison

## Infrastructure Service Comparison

| **Infrastructure Component**   | **AWS**    | **Microsoft Azure**    | **Google Cloud Platform**   |
| ------------------------------ | ---------- | ---------------------- | --------------------------- |
| Compute                        | Amazon EC2 | Azure Virtual Machines | Compute Engine              |
| Storage                        | Amazon S3  | Azure Blob Storage     | Cloud Storage               |
| Networking                     | Amazon VPC | Azure Virtual Network  | Virtual Private Cloud (VPC) |
| Identity and Access Management | AWS IAM    | Microsoft Entra ID     | Cloud IAM                   |

## Guide Questions

### 1. Which cloud provider offers the broadest range of services?

For me, **AWS** has the widest selection of cloud services among the three providers. It provides many choices for different areas such as computing, storage, databases, networking, security, and application development. Because of its large service portfolio, companies can select specific tools depending on the type of project they want to build.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

I would suggest **Microsoft Azure** for an organization that already depends heavily on Microsoft products. Azure is designed to work with many Microsoft technologies, which can make it more convenient to move existing applications and systems to cloud infrastructure. It can also provide a familiar environment for organizations already working with Microsoft services.

### 3. Which platform is widely recognized for Artificial Intelligence, Machine Learning, and Kubernetes services?

**Google Cloud Platform** would be my choice for this area. Google has strong experience in AI and Machine Learning, and its cloud platform also provides Kubernetes-related services for managing containerized applications. These capabilities make Google Cloud a suitable option for projects that involve AI development, machine learning workloads, and modern application deployment.

### 4. What similarities did you observe among the three cloud providers?

After comparing the three providers, I found that **AWS, Microsoft Azure, and Google Cloud Platform** all provide the fundamental services needed to build cloud-based systems. They each have solutions for computing, storing data, networking, and managing user access. Although their service names, interfaces, and features may vary, they all provide similar categories of infrastructure that organizations can use to develop and operate applications in the cloud.
