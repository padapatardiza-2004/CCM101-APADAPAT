# Final Reflection: Missions 1–10

Throughout Missions 1–10, I learned about cloud computing, Linux, Docker, storage, system monitoring, and automation. I applied these lessons by setting up an Ubuntu Server in VirtualBox and deploying WordPress and MariaDB using Docker Compose. I also configured firewall rules, set up persistent storage, and created an automated database backup using a Bash script and cron job. One of the most important things I learned is that a system should not only work properly but also be secure, reliable, and easy to maintain. I also learned the importance of backups, checking logs, and troubleshooting errors. Although I encountered some configuration problems, these activities helped me improve my problem-solving skills and gain more confidence in using Linux and Docker. Missions 1–10 helped me understand cloud infrastructure and system administration better. Through the CloudNova project, I was able to apply what I learned in one system and create documentation that can help others manage and maintain it.
