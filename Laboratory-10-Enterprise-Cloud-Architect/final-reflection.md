# Final Reflection: Missions 1–10

Throughout Missions 1–10, I learned how cloud computing concepts and tools work together to build and maintain an infrastructure. The activities helped me understand cloud platforms, Linux administration, Docker containers, object storage, Infrastructure as Code, system monitoring, and automation. I applied these concepts by preparing an Ubuntu Server virtual machine in VirtualBox and deploying WordPress and MariaDB using Docker Compose. I also configured UFW firewall rules, used a persistent Docker volume for database storage, and created a Bash script for database backups with a scheduled cron job. And the importants I learned is that a working application must also be secure, maintainable, and recoverable. Persistent storage helps protect database data when containers restart, while backups provide another way to recover from data loss. I also learned the importance of checking logs, verifying firewall rules, and documenting the system clearly. I had to troubleshoot configuration issues and verify that the services worked together. These tasks helped me improve my problem-solving skills and become more confident using Linux and Docker. And Missions 1–10 gave me a better understanding of cloud infrastructure and system administration. CloudNova allowed me to combine what I learned into one project and prepare documentation that another administrator can use to understand and maintain the system.
